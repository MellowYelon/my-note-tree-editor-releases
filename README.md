# MY Note Tree Editor AP releases

This repository distributes signed, encrypted delta updates for MY Note Tree Editor AP on Windows x64. It does not contain the application source code or full installers.

AP 1.0.1 updates require the exact supported AP 1.0.0 executable and legal resources of the same edition (KO, EN, or GLOB). Use the installed application's update interface; do not rename or apply another edition's package. Back up your documents before updating.

Release notes describe changes, supported baselines, and verification limitations. Existing program terms and third-party licenses continue to apply. License notices and applicable third-party source archives are included as separate release assets. The application's own source code and signing/encryption keys are not published here.
